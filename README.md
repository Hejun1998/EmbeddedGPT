# EmbeddedGPT

嵌入式硬件设计与开发 AI 助手

## 简介

EmbeddedGPT 是一个基于 WPF 开发的桌面应用程序，旨在通过 AI 技术辅助嵌入式硬件工程师进行电路设计、模块选型、代码生成和方案评审等工作。

## 主要功能

- **硬件模块库**：提供常用嵌入式模块（ESP32、STM32、传感器、通信模块等）的详细信息和预览
- **AI 对话助手**：支持多模型接入，智能回答硬件设计相关问题
- **硬件设计助手**：辅助完成硬件方案设计和模块选型
- **原理图评审**：AI 辅助审查电路原理图
- **代码生成**：自动生成嵌入式设备驱动和应用代码
- **多平台支持**：集成 Cadence、Matlab 等专业工具接口

## 技术栈

- **.NET 8.0 + WPF**：桌面应用框架
- **WebView2**：现代 Web 内容渲染
- **AI 模型接入**：支持多种大语言模型平台
- **模块化架构**：核心库与 UI 分离，便于扩展

## 快速开始

1. 从 [Releases](https://gitee.com/hejun1561520017/embedded-gpt/releases) 下载最新版本
2. 解压后运行 `EmbeddedGPT.exe`
3. 配置 AI 模型 API 密钥即可使用
